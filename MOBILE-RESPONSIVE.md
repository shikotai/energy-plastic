# Energy Plastic: адаптивная мобильная версия

Обновлено: 02.11.2026

## Изменения

- Уменьшены размеры заголовков, отступов и текстовых блоков на телефонах без изменения десктопной композиции.
- Сетки карточек, статистики, этапов, участников и контактов перестраиваются в одну колонку на телефонах.
- Переработаны размеры декоративного кабеля на главной странице, включая модель разреза кабеля и модель продукта. Иллюстрации остаются в пределах видимой карточки даже при ширине 320 px.
- Уплотнены герой-экраны обычных страниц и видео-секция проекта.
- Добавлены безопасный перенос длинных слов/ссылок и `min-width: 0` для гибких сеток.
- Пересмотрены мобильное меню, размеры логотипов, футер и раскладка футера на планшетах.
- Для мобильного меню добавлены `aria-expanded` и `aria-controls`.

## Проверка

Статическая проверка TypeScript: `npm run check` прошла успешно. Проверена геометрия HTML/CSS страниц на ширинах 320, 360, 375, 390, 430, 768, 900 и 1024 px, для переводов RU / KK / EN. Визуальные проверки проведены для основных экранов главной, страницы проекта и типовых внутренних страниц.

## Запуск

```bash
npm ci
npm run dev
```

Для production-сборки используйте `npm run build` после локальной установки зависимостей (`npm ci`). ZIP содержит исходники проекта, без `node_modules` и `.git`.
